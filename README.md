## FAQ

**What does KINGAI do?**
KINGAI builds websites, apps and custom software for small businesses, and provides AI customer-advisor and automation services. The official site is kingai.work.

**What is Wenshu? Is it free?**
Wenshu （文枢） is a free, open-source office suite for Windows and macOS — documents, spreadsheets, presentations and PDF tools in one app. There is no account and no official cloud; files stay in storage you bind yourself. Download it from [Wenshu-Releases](https://github.com/kingaiwork/Wenshu-Releases/releases).

**Where do I download KINGAI OS?**
From [KINGAI-OS-Releases](https://github.com/kingaiwork/KINGAI-OS-Releases/releases). The current images are a Developer Preview (v0.1.0-dev, amd64) — verify the SHA-256 checksum and test in a virtual machine first.
